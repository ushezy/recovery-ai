# Recovery AI Design System
Version: 1.0

---

# Design Philosophy

Recovery AI should feel calm, intelligent, trustworthy, and premium.

Users should immediately feel:

"I trust this product."

Not:

"This is another AI demo."

---

# Design Keywords

- Calm
- Minimal
- Premium
- Human
- Trustworthy
- Focused
- Clean

---

# Visual Direction

Reference Style

- Anthropic (Brand Tone)
- Linear (Product Presentation)
- Notion (Warmth)
- Recovery AI Notebook Style (Identity)

Do not copy any product directly.

Use them only as design inspiration.

# Images

Only use:

- Product Screenshots
- UI Mockups
- Simple Illustrations

Avoid:

- Stock Photos
- AI Robot Images
- Futuristic Graphics
- Medical Icons

---

# Motion

Animation Style

Minimal

Duration

200–300ms

Use only for:

- Button hover
- Fade in
- Smooth scrolling

Avoid excessive motion.

---

# Responsive

Support

Desktop

Tablet

Mobile

Desktop First

All sections must remain visually consistent across devices.

---

# Accessibility

Minimum text contrast

WCAG AA

Buttons must be keyboard accessible.

All images require alt text.

Visible focus states required.

---

# Performance

Use optimized images.

Lazy load below-the-fold assets.

Keep animations lightweight.

Target Lighthouse Score

90+

---

# Brand Rules

Recovery AI is not:

- A medical company
- A hospital
- A fitness app
- A cyberpunk AI product

Recovery AI is:

- Calm
- Intelligent
- Reliable
- Human-centered

Every design decision should reinforce these principles.

---

# Design Principle

**Calm is our competitive advantage.**
